# Pydantic

## 一.基础写法
使用 BaseModel 类进行数据校验，通过创建类来描述数据格式。(类似zod)

写法：
```python
from pydantic import BaseModel

class User(BaseModel):
    username: str
    age: int

@app.post("/users")
def create_user(user: User):
    return user
```

FastAPI 自动完成：
- 接收 JSON 数据
- 转换 Python 对象
- 检查字段类型
- 检查必填字段
- 返回错误信息

注意事项：
- 后端接口的数据格式推荐使用 Pydantic 定义。
- 字段需要添加类型注解。
- Pydantic 主要负责数据验证，不负责业务逻辑。

## 二.Field
Field 用于给模型字段添加额外限制和描述。

1. 基础类型只能限制类型：
```py
class User(BaseModel):
    age: int
```

2. sField可以限制：
```py
class User(BaseModel):
    age: int = Field(
        gt=0,
        lt=10
        )
```
3. 常用参数
| 参数 | 作用 | 示例 |
|---|---|---|
| default | 设置默认值 | Field(default=18) |
| title | 字段标题 | Field(title="用户年龄") |
| description | 字段说明 | Field(description="用户年龄") |
| gt | 大于 | Field(gt=0) |
| ge | 大于等于 | Field(ge=0) |
| lt | 小于 | Field(lt=100) |
| le | 小于等于 | Field(le=100) |
| min_length | 最小长度 | Field(min_length=3) |
| max_length | 最大长度 | Field(max_length=20) |
| pattern | 正则匹配 | Field(pattern="^[a-z]+$") |
