# ORM

## 一.基础语法
### 1.Model（模型定义）
数据库表对应代码中的对象。
>1.表 → Model类  
>2.字段 → 类属性  
>3.数据 → 对象实例  

| 语法 | 作用 | 示例 |
|---|---|---|
| `class` | 定义模型类 | `class User(Base):` |
| `__tablename__` | 指定表名 | `__tablename__ = "users"` |
| `Column()` | 定义字段 | `name = Column(String)` |
| `primary_key` | 设置主键 | `id = Column(Integer, primary_key=True)` |
| `ForeignKey` | 设置外键 | `user_id = Column(Integer, ForeignKey("users.id"))` |
| `relationship()` | 定义表关系 | `orders = relationship("Order")` |

### 2.会话管理
**作用**：管理数据库的操作对象，保存数据，提交事务，回滚错误


| 语法 | 作用 | 示例 |
|---|---|---|
| `Session()` | 创建数据库操作对象 | `db = Session()` |
| `add()` | 添加对象到Session | `db.add(user)` |
| `query()` | 查询数据 | `db.query(User).all()` |
| `commit()` | 提交保存数据 | `db.commit()` |
| `rollback()` | 回滚修改 | `db.rollback()` |
| `refresh()` | 刷新对象数据 | `db.refresh(user)` |
| `close()` | 关闭Session | `db.close()` |

示例：
```py
创建Session：
    db = Session()
添加数据：
    user = User(name="张三")
    db.add(user)
提交保存：
    db.commit()
关闭：
    db.close()
```


### 3.CRUD操作

| 模块 | 作用 | 常用语法 | 示例 |
|---|---|---|---|
| Model（模型） | 表映射成对象 | `class`、`Column`、`primary_key` | `class User(Base):`<br>`id = Column(Integer, primary_key=True)` |
| Create（新增） | 添加数据 | `add()`、`commit()` | `user = User(name="张三")`<br>`db.add(user)`<br>`db.commit()` |
| Read（查询） | 获取数据 | `query()`、`filter()`、`first()`、`all()` | `db.query(User)`<br>`.filter(User.id==1)`<br>`.first()` |
| Update（修改） | 更新数据 | 修改属性、`commit()` | `user.name="李四"`<br>`db.commit()` |
| Delete（删除） | 删除数据 | `delete()`、`commit()` | `db.delete(user)`<br>`db.commit()` |

### 4.示例
```py
    #连接数据库：
    engine = create_engine("数据库地址")
    #创建 ORM 基础类：
    Base = declarative_base()

    # 创建 User 模型，对应 users 表
    class User(Base):
        # 指定数据库表名
        __tablename__ = "users"
        # 定义 id 字段，并设置为主键
        id = Column(Integer, primary_key=True)
        # 定义 name 字段，类型为字符串
        name = Column(String)


    # 创建 Session 工厂，绑定数据库连接
    Session = sessionmaker(bind=engine)
    # 创建数据库操作对象
    db = Session()

    # 创建 User 对象（一条数据）
    user = User(name="张三")
    # 将数据加入 Session
    db.add(user)
    # 提交事务，保存到数据库
    db.commit()
```

## 二.查询操作
Query用于通过 ORM 查询数据库数据。

### 1.常用查询语法

| 语法 | 作用 | 示例 |
|---|---|---|
| `all()` | 查询全部数据 | `db.query(User).all()` |
| `first()` | 获取第一条数据 | `db.query(User).first()` |
| `get()` | 根据主键查询 | `db.query(User).get(1)` |
| `filter()` | 条件查询 | `db.query(User).filter(User.id==1)` |
| `order_by()` | 排序查询 | `db.query(User).order_by(User.age)` |
| `limit()` | 限制数量 | `db.query(User).limit(10)` |
| `offset()` | 跳过数据（分页） | `db.query(User).offset(10)` |
| `like()` | 模糊查询 | `User.name.like("%张%")` |
| `count()` | 统计数量 | `db.query(User).count()` |
| `join()` | 多表查询 | `db.query(User).join(Order)` |

### 2.SQL对应关系
|SQL|ORM|
|-|-|
|SELECT|query()|
|WHERE|filter()|
|ORDER BY|order_by()|
|LIMIT|limit()|
|LIKE|like()|
|COUNT|count()|
|JOIN|join()|


## 三.ORM Relationship（关系映射）

**作用**：Relationship用于表示数据库表之间的关系。

> 对应MySQL：外键 -> 表关联（JOIN）
> ORM：Model对象 -> Model对象 -> 访问关联数据
 
### 1.主要知识点

| 知识点 | 作用 |
|---|---|
| Column()| 定义数据库表里的一个字段 |
| ForeignKey（外键） | 设置外键，建立数据库表之间关联 |
| relationship() | 可将表当做对象进行访问(users.id) |
| back_populates |双向关联|
| secondary |多对多中间表|
| cascade |设置级联操作|
| Cascade（级联） | 关联数据一起新增、修改、删除 |

### 2.常见关系
#### (1)一对一
```py
class A(Base):
    id = Column(Integer, primary_key=True)
    # 把想要链接的b表的id定义一个字段
    b_id = Column(
        # 用来存放数字
        Integer,
        # 用来连接b表单的外键
        ForeignKey("b.id")
        # 表示一个用户只能对应一个信息
        unique=True
    )
```

#### (2)一对多（最常用）
同上，只少了 `unique=True` 一对一的约束信息

#### (3)多对多+双向+对象访问
需要使用中间表
```py
# 中间表
user_role = Table(
    "user_role",
    Base.metadata,
    Column("user_id", ForeignKey("users.id")),
    Column("role_id", ForeignKey("roles.id"))
)

# 用户表
class User(Base):
    __tablename__ = "users"
    id = Column(Integer, primary_key=True)

    #对象访问
    roles = relationship(
        "Role",
        #多对多的中间表
        secondary=user_role,
        #双向连接
        back_populates="users"
    )

# 角色表
class Role(Base):
    __tablename__ = "roles"
    id = Column(Integer, primary_key=True)

    users = relationship(
        "User",
        secondary=user_role,
        back_populates="roles"
    )

```


#### (4)relationship

```py
# 1.一对多："关联的Model"

relationship("Order")

# 2.双向："关联的Model"+ 双向关联

relationship(
    "Order",
    back_populates="user"
)

# 3.多对多："关联的Model" + 中间表

relationship(
    "Role",
    secondary=user_role
)
```
