## 二.基础语法
### 1.常用路由类装饰器
| 装饰器              | HTTP 方法 | 作用           | 常见用途           |
| ---------------- | ------- | ------------ | -------------- |
| `@app.get()`     | GET     | 查询数据         | 获取用户、获取文章列表    |
| `@app.post()`    | POST    | 新增数据         | 登录、注册、新建数据     |
| `@app.put()`     | PUT     | 修改整个资源       | 修改用户全部信息       |
| `@app.patch()`   | PATCH   | 修改部分资源       | 修改昵称、头像等部分字段   |
| `@app.delete()`  | DELETE  | 删除数据         | 删除用户、删除文章      |

### 2. 路由管理（APIRouter）
APIRouter用于创建独立路由。
写法：
```python
#users.py：
from fastapi import APIRouter
router = APIRouter()

@router.get("/users")
def get_users():
    return []

#main.py：
from users import router
app.include_router(router)
```

### 3.完整运行流程
```python
#1.导入fastapi
from fastapi import FastAPI
#2.实例化
app = FastAPI()
#3.写路由接口
@app.get("/users")
def get_users():
    #4.直接返回数据，自动转换为 JSON。

```

## 三.请求和响应
### 1. 请求参数（Request Parameters）
FastAPI 根据参数位置，将请求数据分为三种：

| 类型 | 作用 | 常见场景 | 注意 |
|---|---|---|---|
| Path 参数 | 从 URL 路径中获取数据 | 查询指定 ID 的用户 | 参数必须定义在 URL 中。 |
| Query 参数 | 从 URL 查询参数中获取数据 | 分页、搜索、筛选 | 参数通常用于查询条件。 |
| Body 参数 | 从请求体 JSON 中获取数据 | 注册、登录、提交表单 | 参数通常用于 POST、PUT、PATCH 请求。 |

写法：
```python
#Path 参数：
@app.get("/users/{user_id}")
def get_user(user_id: int):
    return {"id": user_id}

#Query 参数：
@app.get("/users")
def get_users(page: int = 1):
    return {"page": page}

#Body 参数：
@app.post("/users")
def create_user(user: User):
    return user
```
核心特点：

- FastAPI 会根据类型注解自动解析参数。
- 自动完成类型转换。
- 参数类型错误时自动返回错误信息。

### 2.FastAPI响应
| 语法 | 作用 |
|---|---|
|return|直接返回数据|
|response_model|约束返回格式|
|status_code|设置状态码|
|Response|手动控制响应|

|JSONResponse|自定义 JSON|
|FileResponse|返回文件|
|StreamingResponse|流式返回|

#### (1)直接返回数据
最基础的响应方式，FastAPI 会自动转换为 JSON。
```python
@app.get("/users")
def get_users():
    return {
        "name": "张三"
    }
```
#### (2)response_model
限制接口返回的数据格式。
```python
class UserOut(BaseModel):
    username: str
    age: int

@app.get("/users", response_model=UserOut)
def get_user():
    return {
        "username": "张三",
        "age": 18
    }
```
#### (3)status_code
设置 HTTP 响应状态码。
```python
@app.post(
    "/users",
    status_code=201
)
def create_user():
    return {}
```
#### (4)Response
手动控制响应。
| 功能 | 作用 |
|---|---|
|status_code|修改状态码|
|headers|设置响应头|
|cookies|设置 Cookie|
```python
from fastapi import Response

@app.get("/")
def test(response: Response):
    response.status_code = 201

    return {
        "msg": "success"
    }
```
#### (5). 特殊响应
##### JSONResponse
自定义 JSON 返回。
```python
return JSONResponse(
    content={"msg":"ok"},
    status_code=200
)
```
##### FileResponse
返回文件。
```python
return FileResponse("test.pdf")
```
##### StreamingResponse
流式返回数据。
常用于：
- AI 对话流式输出
- SSE
- 大文件传输

## 四.依赖注入(Dependency Injection)
**介绍**：让 FastAPI 自动调用某个函数，并把结果传入接口。本质是函数封装让代码复用，用`Depends()`让 FastAPI 管理函数调用(可嵌套依赖)

### 1. 基础语法
```py
from fastapi import Depends

def get_user():
    return "用户信息"

@app.get("/user")
def user(
    user = Depends(get_user)
):
    return user
```

### 2. 常见使用场景
#### (1)JWT认证（最常用）
```py
def get_current_user():
    token = 获取token()
    user = 验证token()
    return user
接口：
    @app.get("/profile")
    def profile(
        user = Depends(get_current_user)
    ):
        return user
```
### ② 数据库连接
```py
def get_db():
    db = 创建数据库连接()
    yield db
    db.close()
```
