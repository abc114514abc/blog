## 二.基础语法
### 1.常用路由类装饰器
| 装饰器              | HTTP 方法 | 作用           | 常见用途           |
| ---------------- | ------- | ------------ | -------------- |
| `@app.get()`     | GET     | 查询数据         | 获取用户、获取文章列表    |
| `@app.post()`    | POST    | 新增数据         | 登录、注册、新建数据     |
| `@app.put()`     | PUT     | 修改整个资源       | 修改用户全部信息       |
| `@app.patch()`   | PATCH   | 修改部分资源       | 修改昵称、头像等部分字段   |
| `@app.delete()`  | DELETE  | 删除数据         | 删除用户、删除文章      |

### 2.完整流程
```python
#1.导入fastapi
from fastapi import FastAPI
#2.实例化
app = FastAPI()
#3.写路由接口
@app.get("/users")
def get_users():
    #4.直接返回数据，自动转换为 JSON。
    return []
```

## 三.请求和响应
### 1. 请求参数（Request Parameters）
FastAPI 根据参数位置，将请求数据分为三种：

| 类型 | 作用 | 常见场景 | 注意 |
|---|---|---|---|
| Path 参数 | 从 URL 路径中获取数据 | 查询指定 ID 的用户 | 参数必须定义在 URL 中。 |
| Query 参数 | 从 URL 查询参数中获取数据 | 分页、搜索、筛选 | 参数通常用于查询条件。 |
| Body 参数 | 从请求体 JSON 中获取数据 | 注册、登录、提交表单 | 参数通常用于 POST、PUT、PATCH 请求。 |

写法：
```python
#Path 参数：
@app.get("/users/{user_id}")
def get_user(user_id: int):
    return {"id": user_id}

#Query 参数：
@app.get("/users")
def get_users(page: int = 1):
    return {"page": page}

#Body 参数：
@app.post("/users")
def create_user(user: User):
    return user
```
核心特点：

- FastAPI 会根据类型注解自动解析参数。
- 自动完成类型转换。
- 参数类型错误时自动返回错误信息。

### 响应
响应模型用于约束后端返回给客户端的数据格式。
作用：
- 定义返回数据结构
- 自动校验返回数据
- 过滤多余字段
- 自动生成接口文档
- 保证接口返回格式统一
```py
from pydantic import BaseModel


class UserOut(BaseModel):
    username: str
    age: int


@app.get("/users", response_model=UserOut)
def get_user():
    return {
        "username": "张三",
        "age": 18
    }
```


##3 常用配置

response_model_exclude

排除指定字段。

```py
@app.get(
    "/users",
    response_model=UserOut,
    response_model_exclude={"password"}
)


response_model_include

只返回指定字段。


@app.get(
    "/users",
    response_model=UserOut,
    response_model_include={"username"}
)
```

### 注意事项

- 请求模型和响应模型通常不要共用一个。
- 密码、token等敏感字段应该通过响应模型隐藏。
- response_model 是接口输出规范，不影响数据库结构。
- 大型项目通常为创建、查询、更新分别定义模型。





















### 3. 路由管理（APIRouter）
@app.get()
@app.post()

APIRouter用于创建独立路由。

写法：
```python
#users.py：
from fastapi import APIRouter
router = APIRouter()

@router.get("/users")
def get_users():
    return []

#main.py：
from users import router
app.include_router(router)
```
