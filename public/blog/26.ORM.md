# ORM

## 一.基础语法
### 1.Model（模型定义）
数据库表对应代码中的对象。
>1.表 → Model类  
>2.字段 → 类属性  
>3.数据 → 对象实例  

| 语法 | 作用 | 示例 |
|---|---|---|
| `class` | 定义模型类 | `class User(Base):` |
| `__tablename__` | 指定表名 | `__tablename__ = "users"` |
| `Column()` | 定义字段 | `name = Column(String)` |
| `primary_key` | 设置主键 | `id = Column(Integer, primary_key=True)` |
| `ForeignKey` | 设置外键 | `user_id = Column(Integer, ForeignKey("users.id"))` |
| `relationship()` | 定义表关系 | `orders = relationship("Order")` |


---

## 简单案例
```py
class User(Base):

    __tablename__ = "users"

    id = Column(
        Integer,
        primary_key=True
    )

    name = Column(
        String
    )

    orders = relationship(
        "Order"
    )
```

### 2..CRUD操作

| 模块 | 作用 | 常用语法 | 示例 |
|---|---|---|---|
| Model（模型） | 表映射成对象 | `class`、`Column`、`primary_key` | `class User(Base):`<br>`id = Column(Integer, primary_key=True)` |
| Create（新增） | 添加数据 | `add()`、`commit()` | `user = User(name="张三")`<br>`db.add(user)`<br>`db.commit()` |
| Read（查询） | 获取数据 | `query()`、`filter()`、`first()`、`all()` | `db.query(User)`<br>`.filter(User.id==1)`<br>`.first()` |
| Update（修改） | 更新数据 | 修改属性、`commit()` | `user.name="李四"`<br>`db.commit()` |
| Delete（删除） | 删除数据 | `delete()`、`commit()` | `db.delete(user)`<br>`db.commit()` |


```py
连接数据库：
    engine = create_engine("数据库地址")
创建 ORM 基础类：
    Base = declarative_base()
定义数据库模型：

    # 创建 User 模型，对应 users 表
    class User(Base):
        # 指定数据库表名
        __tablename__ = "users"
        # 定义 id 字段，并设置为主键
        id = Column(Integer, primary_key=True)
        # 定义 name 字段，类型为字符串
        name = Column(String)

创建 Session：
    # 创建 Session 工厂，绑定数据库连接
    Session = sessionmaker(bind=engine)

    # 创建数据库操作对象
    db = Session()


操作数据库：
    # 创建 User 对象（一条数据）
    user = User(name="张三")
    # 将数据加入 Session
    db.add(user)
    # 提交事务，保存到数据库
    db.commit()
    commit
```
