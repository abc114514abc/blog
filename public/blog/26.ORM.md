# ORM

## 一.Model（模型定义）
数据库表对应代码中的对象。

>表 → Model类
>字段 → 类属性
>数据 → 对象实例

```py
    class User:
        id
        name
        age
```

## 二.CRUD操作
### Create（新增）
模板：
···
    user = User(name="张三")

    save(user)


对应：

    INSERT


---

### Read（查询）

作用：

获取数据。


模板：

    User.query.all()


常用：

|语法|作用|
|-|-|
|all|查询全部|
|first|获取第一条|
|filter|条件查询|


---

### Update（修改）

作用：

更新数据。


模板：

    user.name = "李四"

    save(user)


对应：

    UPDATE


---

### Delete（删除）

作用：

删除数据。


模板：

    delete(user)


对应：

    DELETE


---

## 总结

|内容|作用|
|-|-|
|Model|定义数据库表|
|Create|新增数据|
|Read|查询数据|
|Update|修改数据|
|Delete|删除数据|
